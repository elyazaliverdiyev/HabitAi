# HabitAI — Гайдлайн анимаций (Apple-стиль)

> Единая система движения. Обязателен для всех новых компонентов и рефакторингов.
> Токены: `src/utils/motionPresets.ts` (канонические имена `motion*`).

## Проблема, которую решает

Аудит (авг 2026): **57 spring-анимаций с 8 разными stiffness (200–500), 4 разных bezier-кривых, длительности от 0.15с до 2с** — каждый компонент анимировался «как захотел», отсюда ощущение случайности и глючности.

## Правила

### 1. Только токены — никаких inline-параметров
```ts
// ❌ Плохо
transition={{ type: 'spring', stiffness: 350, damping: 28 }}

// ✅ Хорошо
import { motionContainer } from '../utils/motionPresets';
transition={motionContainer}
```

### 2. Шесть уровней физики — по назначению

| Токен | Для чего | Характер |
|---|---|---|
| `motionPress` | кнопки, чекбоксы, сегменты, тапы | мгновенно, без отскока |
| `motionControl` | слайдеры, toggle, drag | плотно, «тягуче», без отскока |
| `motionContainer` | карточки, списки, панели | мягко, bounce ≤ 0.05 |
| `motionSheet` | модалки, шторки, поповеры | плавно, без желе |
| `motionPage` | переходы экранов/табов | направленный сдвиг |
| `motionCelebrate` | завершение, стрик, ачивка | **единственный с явным bounce** |

### 3. Длительности
- Вход/появление: **≤ 0.35с**
- Выход/исчезание: **≤ 0.2с** (`durationFast`, `easeAccel`)
- Всё длиннее 0.5с — ошибка, кроме осознанных celebrate-сцен (дыхание, частицы).

### 4. Функциональное ≠ Праздничное
- Отметка привычки, открытие модалки, переключение — **функциональные**: без overshoot, быстро, тихо.
- Completeness, milestone, level-up — **праздничные**: только здесь допустим bounce, конфетти, звук.

### 5. Easing-кривые (для tween)
- `easeApple` — стандарт (прогресс, цвет, морфинг)
- `easeDecel` — вход контента
- `easeAccel` — выход

### 6. `prefers-reduced-motion`
Все петлевые/декоративные анимации (частицы, дыхание, шиммер) обязаны проверять `useReducedMotion()` и отключаться/упрощаться.

### 7. Что НЕ анимировать
- Текстовые значения (числа меняются — без анимации, кроме CountUp)
- Цвет фона экрана при вводе данных
- Что-либо при простом hover на мобильном

### 8. CSS-переходы (Tailwind `duration-*`)
Единая шкала: `duration-200` (мелкие UI-элементы) / `duration-300` (стандарт) / `duration-500` (смена темы, крупные морфинги). Никаких 700/1000/75.
Easing только `ease-in-out` (движение) и `ease-out` (появление).

## Миграция

Старые имена (`springSnappy`, `springGentle`, `dockSpring`…) сохранены как @deprecated-алиасы к каноническим токенам — код не ломается, но новые правки должны использовать `motion*` имена. При касании старого компонента — замени его inline-переходы на токены.
